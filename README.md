# libbitcoin-server

The client interfaces of Bitcoin Server, and the `bs` executable.

Documentation is at [libbitcoin.org/lib/server](https://libbitcoin.org/lib/server.html).

Download [Bitcoin Server (`bs`)](https://libbitcoin.org/download/index.html).

| | |
| - | - |
| Depends on | [libbitcoin-node](https://github.com/libbitcoin/libbitcoin-node) |
| Header | `<bitcoin/server.hpp>` |
| Namespace | `libbitcoin::server` |
| Package | `libbitcoin-server` (pkg-config) |

To install and run `bs`, see [Getting started](https://libbitcoin.org/start/index.html).

Libbitcoin is a set of cross-platform C++20 libraries for building Bitcoin applications. See [all libraries](https://libbitcoin.org/lib/index.html) and [building from source](https://libbitcoin.org/building/index.html).
